# Release Artifacts

This directory is reserved for version-specific release checklists, evaluation summaries, migration notes, and other artifacts that should live with a formal Ngabo release.

Examples:

```text
docs/release/v0.1.0-checklist.md
docs/release/v0.2.0-evaluation.md
docs/release/v1.0.0-production-readiness.md
```

Product maturity and release criteria are governed by `ROADMAP.md`; branch/version mechanics are governed by `CONTRIBUTING.md` and `docs/RELEASE_POLICY.md`.
