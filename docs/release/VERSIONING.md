# Versioning Summary

Ngabo uses Semantic Versioning 2.0.0.

```text
MAJOR.MINOR.PATCH
```

During pre-1.0 development:

- fixes normally increment PATCH;
- feature/release milestones normally increment MINOR;
- breaking changes are explicitly marked and normally increment MINOR;
- `1.0.0` is a deliberate production-readiness milestone, never an automatic breaking-change bump.

See `ROADMAP.md` for maturity stages and `CONTRIBUTING.md` for release mechanics.
