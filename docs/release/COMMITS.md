# Conventional Commits Summary

Ngabo uses Conventional Commits 1.0.0.

```text
<type>[optional scope]: <description>
```

Preferred types:

`feat`, `fix`, `docs`, `test`, `refactor`, `perf`, `build`, `ci`, `chore`, `revert`.

Preferred scopes:

`web`, `core`, `surveillance`, `agent`, `evidence`, `events`, `data`, `eval`, `infra`, `docs`, `release`.

Breaking changes use `!` and/or a `BREAKING CHANGE:` footer.

See `CONTRIBUTING.md` for examples and rules.
